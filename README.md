# SupplySignal AI

SupplySignal AI is an operator-controlled application for a consented supplier
call, structured delivery-risk review, and auditable evidence.

This initial shell contains no credentials and does not make external calls.

## Local development

Use Node.js 22.23.1 and pnpm 11.20.0.

```text
pnpm install
pnpm dev
```
